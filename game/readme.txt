This folder includes all game files to serve on your browser.
Unpack using your favorite unarchiver program.

***Use Python web server to get it works.***

Here is an example of how to run an instance of the game locally using Python 3 HTTP webserver:
    - First, copy the assets to a chosen directory (i.e. MYPATH\MYGAME).
    - Install Python.
    - Run Windows Powershell or Cmd, or Terminal on Linux/BSD systems.

Then, enter the following:
 python3 -m http.server
 -> Or in Python 2.x
 python -m http.server
